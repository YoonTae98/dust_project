# 운행 후 PM10 효과 추정: 연구용 계산·검증 코드

화면 변경과 분리한 독립 Python 모듈입니다. 현재 사이트에 연결하지 않으며, 추정 효과가 검증되기 전에는 연결해서는 안 됩니다. 사용자가 지정한 공식 43.3%를 별도 기준 시나리오로 제공합니다. 현재 프로젝트의 측정소 농도만으로 실제 청소 효과를 추정할 수 없으므로 실제 대구 저감률이나 대구 자료로 학습한 모델을 제공하지 않습니다. official_reference_model.json은 공식 수치를 옮겨둔 조건부 시나리오입니다.

## 공식 기준계수 43.3% (사용자 제공 근거 확인 완료)

2023-04-26 환경부·한국환경공단 보도자료, 미세먼지 종합포털:
https://www.airkorea.or.kr/portal/web/board/7/7173/?page=13
제목: (환경부) 495개 집중관리도로 청소 전후 미세먼지 측정, 평균 43.7% 감소

본문의 차량 유형별 분석은 분진흡입 청소차 43.3%입니다. 전체 평균 43.7%와 구분합니다. 측정 대상은 도로재비산먼지 PM10이며, 청소 시작 10~30분 전과 청소 후 30~60분의 비교입니다. 구역 전체의 측정소 대기 PM10에 동일 효과가 발생한다는 근거는 아닙니다. 도로별 일률적 적용과 대구로의 전이는 이 프로젝트의 시나리오 가정입니다.

    청소한 도로 구간의 재비산먼지 PM10 시나리오 = 이전 농도 × (1 - 0.433)
    미청소 구간 = 이전 농도
    동일 평가 도로망의 전후 농도 = 각 구간 농도의 도로 길이 가중 평균

모든 경로에서 '청소한 도로만' 평균을 내면 감소율이 모두 43.3%가 됩니다. 따라서 같은 구역의 같은 평가 도로망을 분모로 두고 청소한 구간과 미청소 구간을 함께 평가합니다. 경로가 커버하는 고농도 도로가 다르면 구역 도로망 기준 효과도 달라질 수 있습니다. 같은 도로를 청소하면 경로 순서가 달라도 본 모델의 결과는 같습니다. 시간별 재축적 자료 없이 순서에 대한 보너스를 만들지 않습니다.

공식 기준 모델 만들기 및 적용:

    python3 effect_model.py reference official_reference_model.json
    python3 effect_model.py compare official_reference_model.json case_template.json comparison.json

case_template.json의 빈 segments 및 거리/청소 구간 목록을 채워야 합니다. 여기에 필요한 것은 도로재비산먼지 농도 및 실제 청소 구간입니다. 현재 앱의 도시대기 IDW 자료는 같은 지표가 아니므로 직접 연결하지 않았습니다. 그 값을 대리지표로 쓰려면 결과 이름도 'PM10 대리지표 기반 청소 우선순위 시뮬레이션' 등으로 바꾸고 실제 농도 저감 예측과 구별해야 합니다.

## 연구에서 확인한 근거와 한계

1. Evaluating urban PM10 pollution benefit induced by street cleaning activities (2009).
https://www.sciencedirect.com/science/article/pii/S1352231009005482
공개 초록은 기계식 청소·물청소 효과를 평가하면서 상풍측과 도시 배경 측정소를 비교해 기상 변동에 따른 감소를 구분했다고 설명합니다. 본 코드가 참고한 것은 이 '비청소 배경 변화와 구별해야 한다'는 평가 원칙입니다. 초록의 제거율을 분진흡입차량의 계수로 가져오지 않았습니다. 본문의 구체적 모델 전체는 확인하지 못했습니다.

2. Real-time PM10 emission rates from paved roads ... Part 2 (2021).
https://doi.org/10.1016/j.atmosenv.2021.118453
공개 초록은 실험 조건에서 청소 직후 PM10 배출률이 일시적으로 증가한 사례를 보고합니다. 따라서 본 코드는 음의 저감효과를 0으로 자르거나 AI의 성능을 강제로 양수로 만들지 않습니다. 배출률과 대기 농도는 다른 지표입니다.

현재 찾은 대구 '분진흡입 청소차량을 이용한 도로재비산먼지 저감 효과 조사'는 발표 목록/서지정보까지만 확인했으며, 수치의 적용 조건과 원자료를 확인하지 못했습니다. 이전에 언급된 제거율을 이 코드에 넣지 않았습니다.

## 이 코드의 모델: 프로젝트 가정이며 논문 원식이 아님

각 관측은 같은 시간대의 청소 구간과 비교 구간에서 수집한 PM10 전후 농도(㎍/㎥)입니다.

    y = (청소구간 전 - 청소구간 후) - (비교구간 전 - 비교구간 후)
    x = 청소구간 전 농도
    beta = sum(x*y) / sum(x*x)
    배경조건 고정 시 청소 후 농도 시나리오 = x * (1-beta)

이는 배경 변화가 청소구간과 비교구간에 같은 크기로 영향을 준다는 가정 및 농도에 비례하는 청소효과라는 가정을 둔 단순 기준모델입니다. 이러한 가정은 검증 대상입니다. 배경 보정만으로 인과관계가 입증되지 않습니다. 교통량 변화·강수·풍향·풍속·다른 배출원·평균회귀 등의 혼란 요인을 통제한 실험 설계가 필요합니다.

차량, 청소 방식, 속도, 도로 조건, 전후 측정 간격, 평가 시간, 측정 장비 및 지표가 같은 자료만 protocol_id 하나로 묶습니다. 단위·대표성·비교구간 선정과 동일 프로토콜 여부는 사람이 검토해야 합니다. 코드의 protocol_id 일치 검사는 그 과학적 적합성을 증명하지 않습니다.

독립 청소 사건별 leave-one-event-out 검증을 수행하여 MAE/RMSE와 '청소 효과 없음' 기준모델의 MAE를 보고합니다. 최소 두 사건은 분할 가능 조건일 뿐 충분한 표본수 기준이 아닙니다. 같은 날·같은 청소 운행에서 나온 반복 측정은 하나의 event_id로 묶어 누수를 줄이세요. 외부 지역·차량·날짜에 대한 검증과 불확실성 평가 전에는 연구용입니다.

## A/B/C/AI 비교 방식

모든 경로에 동일한 평가 도로망을 사용합니다. 각 경로에서 실제 청소되는 도로 구간 ID를 입력하며, 반복 통과는 한 번만 반영합니다. 청소하지 않는 구간은 그대로 두고 전체 평가망에서 길이 가중 평균 전후 농도를 계산합니다. 길이는 실제 도로 길이로 공간 평균을 내기 위한 가중치이며 임의 효과 계수가 아닙니다.

이 값은 '고정 평가 도로망의 길이 가중 도로 인근 PM10 농도 시나리오'입니다. 대구 행정동 전체 면적 평균이나 제거한 먼지 질량, 실제 대기 농도 예보가 아닙니다. 현재 측정소 IDW를 해당 도로 실측으로 자동 치환하지 않습니다. 도로별 영향의 독립성, 청소효과의 전이 가능성, 시간감쇠·공간확산 없음은 추가 가정입니다. 방문 거점이나 선의 근접도만으로 청소한 도로라고 판단하지 않으며, 실제 청소 구간의 매칭이 별도로 필요합니다.

저감률 = (전 - 후) / 전 × 100
기존 평균 = (A 저감률 + B 저감률 + C 저감률) / 3
상대 성능 = (AI 저감률 / 기존 평균 - 1) × 100
저감률 차이(%p)도 별도 출력합니다. 기존 평균이 0 이하이면 상대 성능은 null입니다.

모델이 음수 농도를 예측하거나 평가 농도가 학습 범위를 벗어나면 오류를 냅니다. 효과가 악화되는 결과는 그대로 유지합니다. AI가 유리하도록 계산하지 않습니다.

## 실행

추가 패키지 없이 Python 표준 라이브러리만 사용합니다.

    python3 effect_model.py fit observations_template.csv model.json
    python3 effect_model.py compare model.json case_template.json comparison.json
    python3 -m unittest test_effect_model.py

공식 기준 시나리오는 case_template.json만 채우면 됩니다. 실측으로 계수를 학습하는 fit 경로는 observations_template.csv가 필요합니다. 빈 파일은 명시적 오류를 냅니다.
관측 CSV의 source에는 원자료 파일·논문 표·수집 기록 등 추적 가능한 출처를 넣으세요. event_id는 독립된 청소 사건, observation_id는 개별 측정쌍의 고유 ID입니다.
case의 segments 각 항목은 segment_id, length_km, pm10_before, source 필드를 가져야 합니다. routes에는 실제 경로 길이와 cleaned_segment_ids를 넣습니다. protocol_id는 학습자료와 일치해야 하고 observation_context에는 동일 관측 날짜·시간을 기록합니다.

테스트의 수치는 수학적 검산을 위한 가상 값이며 대구 자료나 제거율의 근거가 아닙니다. 8개 테스트로 배경 변동만 있을 때 가짜 효과가 생기지 않는지, 계수 추정, 공통 도로망 비교, 중복 통과, 음의 효과, 자료 누락, 지표 불일치, 사건별 분할을 확인했습니다. 테스트 통과는 환경 효과 검증을 의미하지 않습니다.
